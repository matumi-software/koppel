# DeviceDrawer

A selected device's details in the wide aside.

- Order: state badge, name, maker; the holder box (`kp-holder`, `data-state`) saying who has the device and what to do; facts as a `kp-kv` list (VID:PID, bus, speed); the role's control (Share switch or Attach/Detach); then its History.
- Close returns the aside to the activity feed.
